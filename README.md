# Naturals Salon & Spa Hyderabad

A modern, responsive salon and spa website designed for Naturals Salon & Spa, Hyderabad.

## 🌐 Live Website

[Visit Naturals Salon & Spa Hyderabad](https://naturals-salon-hyderabad.vercel.app)


## Features

- Responsive design for desktop and mobile
- Home page
- Our Story page
- Services page
- Contact page
- Booking flow
- Mobile-friendly navigation
- Modern salon-focused UI

## Technologies Used

- React
- TypeScript
- Vite
- CSS
- Tailwind CSS
- shadcn/ui

## Project Structure

- `src/pages/` – Website pages
- `src/components/` – Reusable UI components
- `src/hooks/` – Custom React hooks
- `src/lib/` – Utility functions
- `public/` – Images and static assets
